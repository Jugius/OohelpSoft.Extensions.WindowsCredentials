# OohelpSoft.Extensions.WindowsCredentials

A lightweight .NET library for storing and retrieving username/password credentials using the Windows Credential Manager and displaying the native Windows credential prompt.

## Features

- Store credentials in Windows Credential Manager
- Retrieve saved credentials
- Delete saved credentials
- Display the native Windows Security credential dialog
- Support for local and domain accounts
- No external dependencies

## Requirements

- Windows
- .NET 10

## Installation

Install the NuGet package:

```bash
dotnet add package OohelpSoft.Extensions.WindowsCredentials
